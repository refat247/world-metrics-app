# Android Build Guide

## Canonical state

The `android/` project is now version-controlled production source. It was generated by Capacitor 8.5.2, compiled successfully in GitHub Actions, and promoted only after the debug APK build passed.

Current Android baseline:

- Capacitor: 8.5.2
- `minSdkVersion`: 24
- `compileSdkVersion`: 36
- `targetSdkVersion`: 36
- package/application ID: `app.worldmetrics.mobile`

## Windows development

1. Install Node.js 22+ and Android Studio with a current Android SDK.
2. Clone this repository.
3. Double-click `SETUP_ANDROID_WINDOWS.bat`.
4. The script runs `npm ci`, synchronizes the canonical `www/` assets into the existing Android project, and opens Android Studio.
5. Let Android Studio finish Gradle sync.
6. Run on a connected Android device or emulator.

`SETUP_ANDROID_WINDOWS.bat` will create `android/` only as a recovery path if the directory is absent. Normal development uses the committed project.

## Command-line debug build

On macOS/Linux/CI:

```bash
npm ci
npx cap sync android
cd android
./gradlew assembleDebug
```

The debug APK is produced at:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

## Play Store release

Do not reuse the debug build for release. Configure a protected signing key, review versionCode/versionName and production metadata, then build a signed Android App Bundle (`.aab`) and validate it through Google Play internal testing before production rollout.
